# NURPATH Biomedical Initiative — Website v2

Responsive single-page website with dedicated navigation sections for About Us, Research Projects, Team, Publications, Partnerships, Our Principles, and Contact.

## Preview
1. Extract the ZIP.
2. Open `index.html` in a browser. Internet is required to load the Google Fonts; fallback fonts are defined.
3. For local development, use a static server such as VS Code Live Server.
